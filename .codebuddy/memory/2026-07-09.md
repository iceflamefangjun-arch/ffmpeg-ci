# 2026-07-09 工作日志

## clang-shell live+x64 GitHub Actions 编译修复

### 问题
live+x64+debug 在 GitHub Actions (windows + msys2 + clang) 上编译失败:
`ERROR: nvenc requested, but not all dependencies are satisfied: ffnvcodec`

### 根因分析
1. **核心根因**: `env_config.sh` 的 clang-cl wrapper 中, 正则 `^([-/][A-Za-z]+:)(/[a-zA-Z]/.*)$` 错误匹配 `-ID:/a/...` (flag `-I` + Windows路径 `D:/a/...`), 将其解析为 flag `-ID:` + Unix路径 `/a/...`, 然后 `cygpath -w "/a/..."` 转成 `A:\...` (错误的盘符!)
2. **为何只影响 ffnvcodec**: MSYS2 的 pkg-config 对 ffnvcodec 输出 Windows 格式路径 (`D:/a/...`), 而其他依赖输出 Unix 格式 (`/d/a/...`)
3. **附带问题**: x264/fdk-aac/libmfx 的 b-live.sh 只改写 .pc 文件的 `prefix`, 未改写 `includedir`/`libdir`, 导致路径指向非 live 目录
4. **附带问题**: ffmpeg b-live.sh 缺少 `inline_asm_nonlocal_labels` 修复 (player b.sh 有), static/release 构建可能 make 失败

### 修复内容
1. **env_config.sh**: 在 colon 正则前新增 `^[-/]([A-Za-z])([a-zA-Z]:[\\\\/].*)$` 匹配, 检测单字母 flag + Windows盘符路径, 直接 passthrough
2. **x264/b-live.sh, fdk-aac/b-live.sh, libmfx/b-live.sh**: 将 `sed -i` 改为 temp file 方式, 同时改写 `prefix/exec_prefix/libdir/includedir`
3. **ffmpeg/b-live.sh**: 
   - 新增 `inline_asm_nonlocal_labels` 修复 (static/release), 与 player b.sh 一致
   - 新增 `ffnvcodec_include_dir` 变量, 将 ffnvcodec include 路径以 Unix 格式直接加入 CFLAGS/CPPFLAGS (双保险)

### 影响范围
- 修复应覆盖所有 live+x64 组合 (debug/release/static)
- 不影响 player 构建配置 (player 使用 `--disable-nvenc`, 不触发 ffnvcodec 检查)
